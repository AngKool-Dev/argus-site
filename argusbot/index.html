ArgusBot Client-side Minecraft bot

A client-side farming and mining bot for Minecraft 26.2. Automates Skyblock farming with human-like behavior: auto-farm, auto-mine, combat, anti-AFK, idle walking, and chest depositing. On-screen notifications only — never touches public chat.

Features

Automation that respects the client boundary. No server mods required.

Farming

Auto Farm

Scans for mature crops, breaks them through the face/break/verify state chain, chains consecutive harvests in-lane, collects drops, and deposits into chests. Reach-capped at 3.0 blocks.

Mining

Auto Mine

Mines generator blocks on Skyblock islands and Survival worlds. Allowlist of stone family + ores, never cobblestone. No movement key pressed while mining.

Idle

Idle Walking

Wanders safely when no active task is running. Includes fall and drowning guards so the bot does not kill itself between jobs.

Combat

Monster Fighting

Stance-based approach/strike behaviour with nearest-target selection, crit sequences (sprint-off, jump, swing on fall), bounded aiming, and aim-assist mode.

Anti-AFK

Anti-AFK Solver

Detects open container menus with stained glass panes and click-me items, then clicks via container input. Licensing-gated.

Privacy

No Public Chat

All notifications use toasts, a HUD overlay, or the action bar. ArgusBot never sends messages to public chat.

Safety

Reach Guard

Every break attempt is checked against a 3.0-block reach limit. Rejections are logged for review.

Diagnostics

Debug Overlay

DebugLogger with session markers, action rate monitor counters, HUD overlay, toasts, action bar, and debug expand keybind.

Capabilities

01

Replanting

Post-placement hold, bounded turn settlement, dig-wait safety, and read-only recheck diagnostics. Exactly one interaction + one swing per placement.

02

Task Arbitration

Enabled tasks ranked (mining > farming > idle). Standing still beats moving. Deferred tasks start when the active one finishes.

03

Human-Like Pacing

Bounded rotations, reaction delays, swing gating, cooldowns, randomized pauses, idle wander, view drift, and unified idle cadence.

Controls

B

Start / Stop

Toggles the bot on and off. The menu can configure tasks without launching them.

G

Set Home

Marks the current position as home. The bot returns here when idle or after farming.

U

Menu

Opens the ArgusBot settings menu. Toggle farming, mining, idle mode, and environment mode here.
