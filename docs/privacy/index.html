Privacy Policy

Last updated: September 6, 2026

Information We Collect

ARGUS does not collect, store, or process any personal information from visitors to this website. There are no account creation forms, contact forms, newsletter signups, or any other data-entry mechanisms.

Automatically Collected Technical Information

This website makes public API calls to GitHub to retrieve release version and download-count information. These calls do not identify you personally and do not place cookies or tracking identifiers on your device.

Cookies and Local Storage

This website does not use cookies, local storage, session storage, or any similar browser storage mechanisms.

Third-Party Services

This website links to external services operated by third parties:

  • GitHub — release downloads, source code, and release notes
  • Discord — community chat
  • Buy Me a Coffee — voluntary donations
  • PayPal — voluntary donations

These services have their own privacy policies. We encourage you to review them.

Why Information Is Processed

The only processing that occurs is the GitHub API request described above, which is used solely to display the current version and aggregate download statistics on the download page. No individual user data is retained.

Data Retention

Because no personal data is collected, there is no retention period for personal information.

Your Rights

Since we do not collect personal data, there is no personal data to access, correct, delete, or export. If you have questions about this policy, contact us through the GitHub repository linked below.

Children's Privacy

This website does not knowingly collect information from children. If you believe a child has provided us with personal information, contact us through our GitHub repository.

Changes to This Policy

This policy may be updated from time to time. The "Last updated" date at the top indicates when the policy was last revised. Continued use of the website following changes constitutes acceptance of the updated policy.

Contact

For privacy questions, contact the project maintainer through the GitHub repository.
